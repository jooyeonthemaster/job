### 9. 회사 홈페이지 링크 수정 ⭐ 중요
**요청 내용**: 회사 홈페이지 클릭 시 자사 사이트로 리다이렉트되는 문제

**현재 구현 상태**: 🐛 버그 추정
- 파일: `app/companies/[id]/page.tsx` (라인 479-489)
- 현재 코드:
```tsx
{companyDetail.website && (
  <a href={companyDetail.website} target="_blank" rel="noopener noreferrer">
    회사 홈페이지
  </a>
)}
```
- **가능한 원인**:
  1. `companyDetail.website` 데이터가 비어있거나 상대 경로
  2. https:// 프로토콜 누락
  3. DB에 잘못된 URL 저장

**구현 계획**:
```
수정 파일: app/companies/[id]/page.tsx
작업 내용:
1. website URL이 http/https로 시작하는지 확인
2. 시작하지 않으면 https:// 자동 추가
3. 빈 값이면 링크 숨김

예시 코드:
const websiteUrl = companyDetail.website?.startsWith('http')
  ? companyDetail.website
  : `https://${companyDetail.website}`;

예상 작업량: 20분
```
